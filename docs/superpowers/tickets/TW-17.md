**Goal:** Replace Yahoo 1-minute polling with minute buckets derived from live Shioaji quote events.

**Depends on:** TW-03, TW-14, TW-15

## Work
- Aggregate events into Asia/Taipei/XTAI 1-minute OHLCV buckets.
- Define volume semantics from actual Shioaji event fields; duplicate/reconnect events must not double-count.
- Persist/emit buckets through explicit forming/completed semantics compatible with existing intraday chart.
- Disable old 60-second Yahoo intraday fetch job in Taiwan mode.
- Gaps after disconnect remain gaps; never synthesize trades.
