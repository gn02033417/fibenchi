# TW-12 — Aggregate Shioaji Kbars into settled daily OHLCV and gap-based sync

**Goal:** Replace Yahoo daily-history reconciliation with settled XTAI daily bars built from Shioaji minute Kbars and fetched only for DB gaps.

**Depends on:** TW-03, TW-10, TW-11  
**Branch:** `tw-12-settled-daily-sync`

## Interfaces produced
Pure `aggregate_daily_ohlcv(minute_bars, venue)` plus gap-based sync using HistoricalDataQueue and PriceRepository.

## Work
- Aggregate XTAI minute bars into daily open/high/low/close/volume.
- Persist only completed sessions; live intraday and settled daily are separate paths.
- Initial asset backfill: `1y + WARMUP_DAYS`; 2y/5y requests add only missing ranges.
- Scheduled close sync computes missing XTAI sessions and fetches only gaps.
- Remove Taiwan-path dependence on Yahoo `drop_unsettled_last_bar` reconciliation.
- Invalidate/re-warm indicator caches after settled data changes.

## Verification
Run focused daily aggregation/price-sync tests plus indicator regression.

## Acceptance
- [ ] Deterministic minute fixture produces exact daily OHLCV.
- [ ] Open session is not persisted as settled daily close.
- [ ] Re-running sync with no gaps makes no historical calls.
