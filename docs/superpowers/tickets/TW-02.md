# TW-02 — Migrate legacy Yahoo-style Taiwan symbols safely

**Goal:** Convert proven `.TW`/`.TWO` Taiwan assets to raw codes without damaging relationships or foreign symbols.

**Depends on:** TW-01  
**Branch:** `tw-02-normalize-taiwan-symbols`

## Files
- Create `backend/alembic/versions/0022_normalize_taiwan_symbols.py`
- Create `backend/app/services/taiwan_symbol_migration.py`
- Create `backend/tests/migrations/test_normalize_taiwan_symbols.py`

## Work
- Convert only suffixes proven Taiwan: `2330.TW -> 2330`, `6488.TWO -> 6488`, `0050.TW -> 0050`.
- Update symbols in place; do not delete/recreate Asset rows.
- Normalize matching SymbolDirectory rows.
- Detect collisions such as both `2330` and `2330.TW`; fail with actionable error rather than overwrite.
- Leave non-Taiwan/unsuffixed overseas rows untouched.
