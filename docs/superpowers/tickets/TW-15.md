# TW-15 — Replace poll-based backend quote SSE with event-driven live quote state

**Goal:** Keep the browser `/api/quotes/stream` contract while removing provider polling from the backend SSE loop.

**Depends on:** TW-14  
**Branch:** `tw-15-event-driven-quote-sse`

## Files
- `backend/app/services/quote_service.py`
- `backend/app/routers/quotes.py`
- `backend/app/main.py`
- `backend/tests/services/test_quote_service.py`
- Add/update quote-stream integration tests

## Interfaces consumed
`LiveQuoteStore` listener/async subscription API from TW-14.

## Work
- First browser SSE frame returns the current quote snapshot for relevant tracked symbols.
- Subsequent `quotes` events contain only changed symbols (preserve delta compression).
- Provider/sidecar polling loops must not run merely because a browser SSE client is connected.
- Browser cancellation unregisters listeners cleanly.
- Surface provider disconnected state without fabricating new prices.
