# TW-13 — Add realtime-priority selection model and deterministic 180-slot wanted set

**Goal:** Define a pure deterministic allocator for which tracked symbols deserve Shioaji realtime slots.

**Depends on:** TW-01, TW-09  
**Branch:** `tw-13-realtime-priority`

## Interfaces produced
`compute_wanted_symbols(...) -> list[str]` capped by `SHIOAJI_MAX_SUBSCRIPTIONS`, with explicit priority inputs for active asset, realtime-priority groups, active group, recent symbols, and remaining tracked assets.

## Work
- Priority order: active asset > realtime-priority groups > active group > recent > other tracked.
- De-duplicate symbols across groups/tags.
- Deterministic tie-break/order.
- Enforce configurable cap default 180.
- Add API contract to toggle `Group.realtime_priority`; add lightweight demand-control seam for active asset/group.
