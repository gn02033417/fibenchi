## Work
- Search only PostgreSQL `symbol_directory`; remove `source=yahoo` and fallback behavior from Taiwan runtime.
- Support exact/prefix/substring code and Chinese-name search with deterministic ordering.
- `create_asset` requires active supported directory row and copies name/exchange/type/TWD.
- Reject AAPL/NVDA and inactive/unsupported rows clearly.
- Prove typing/search does not call Shioaji or Yahoo.
